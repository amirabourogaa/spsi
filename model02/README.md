# SPSI — Site vitrine

Site vitrine responsive en HTML + Tailwind CSS + JavaScript.

## Lancer le site
Ouvrir `index.html` dans un navigateur ou utiliser Live Server.

## À modifier avant production
- Remplacer les images de démonstration dans `index.html`.
- Vérifier le numéro WhatsApp et les coordonnées.
- Connecter le formulaire à un backend ou service email.
- Pour une production SEO optimale, compiler Tailwind au lieu du CDN.
- Ajouter `sitemap.xml`, `robots.txt` et éventuellement une page Mentions légales / Politique de confidentialité.
